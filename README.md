# aman-saimbhi.github.io

My personal site — <https://aman-saimbhi.github.io/>

Static HTML, CSS and JavaScript. No build step and no dependencies.

## Running it locally

ES modules are blocked under `file://`, so serve it over HTTP:

```sh
python3 -m http.server 8000
```
